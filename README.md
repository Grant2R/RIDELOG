# RIDELOG 

RIDELOG is a mountain bike training log i'm building to keep track of my rides and see how i'm progressing.

## what it does

- lets me log rides by trail, miles, and time
- saves my rides so they don't disappear when i close the website
- shows my ride history
- has a dark themed website

## what i'm using

- Python
- FastAPI
- SQLite
- HTML, CSS, and JavaScript

## how to run it

1. clone the repo
2. install FastAPI with `python -m pip install fastapi`
3. run the app with `python -m fastapi dev main.py`
4. open http://127.0.0.1:8000 in your browser
